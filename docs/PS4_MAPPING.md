## 2. Pipeline in one picture

```text
generate_data.py  ->  data/raw/*.csv (dirty)  ->  clean_data.py (Pandas)  ->  data/cleaned/
        |                                                                     
        +-> data/clean/*.csv -> load_to_mysql.py -> MySQL (30 tables)
                                   |  sentiment.py   (TextBlob)          -> reviews, sentiment_keywords
                                   |  forecast.py    (Holt-Winters)      -> network_forecast, demand_forecast
                                   |  segmentation.py (K-Means)          -> user_segments, station_clusters
                                   |  recharge_predictions.py            -> recharge_predictions
                                   +-> CALL sp_refresh_warehouse()       -> dw_* star schema + v_* views
                                          |-> Spring Boot AnalyticsService (SQL) -> /api/analytics/* -> React Insights
                                          |-> db/05_bi_queries.sql, Metabase / Workbench
visual_report.py -> analytics/reports/*.png        make_notebook.py -> VoltSlot_Analytics.ipynb
```

Run everything with `python analytics/run_all.py` (see `analytics/README.md`).

## 3. Honest notes for the examiner

- **Metabase** itself is not part of the repository. The six `v_*` views are designed to be connected to it (or to any BI tool). An optional way to try it: `docker run -p 3000:3000 metabase/metabase`, then add a MySQL database `chargeiq`. This step was not tested in this project.
- The forecast evaluation shows Holt-Winters and a 7-day moving average are about equally accurate on this synthetic data; both clearly beat seasonal-naive.
- The data is simulated with built-in patterns (commute peaks, monsoon dip, holidays), so the discovered insights confirm those patterns rather than reveal real-world behaviour.

## 4. Five-minute PS-IV demo

1. Open `analytics/reports/` and show 2-3 charts (heat-map, forecast, sentiment).
2. Show `data/cleaning_log.csv`: what was dirty and how it was fixed.
3. In MySQL Workbench run `SELECT * FROM v_zone_summary;` and one query from `db/05_bi_queries.sql`.
4. Log in as admin, open Insights, change the date filter and zone, walk through Overview, Demand & Forecast, Customers, Bookings & Funnel, Reviews & Sentiment, Weather & Events.
5. Admin console: press Refresh warehouse to show the star schema being rebuilt.
